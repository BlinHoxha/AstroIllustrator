# AstroIllustrator Documentation v2.1

Updated 22 October 2026. These eight PDFs consolidate the original v2.0 specification with:

- Solution rename: AstroIllustrator.sln, AstroIllustrator.Api/Core/Infrastructure, Python astro_renderer.
- Worldwide WGS84 observer coordinates, elevation, time zones and local/UTC conversion.
- Accurate Sun/Moon/planet ephemerides and horizon projections.
- Sunset/sunrise-relative observing times, twilight categories, no-sunset handling.
- AstronomicalEvent sky scenes: conjunctions, Moon-planet pairings, planetary alignments, twilight visibility.
- Actual angular separations, below-horizon warnings, event search across date ranges.
- AI natural-language prompt extraction into validated typed requests, never fabricated scientific geometry.

Illustrative dates in examples are not confirmed conjunction dates.
